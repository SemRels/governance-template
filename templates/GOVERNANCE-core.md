# Governance

## Overview

This core SemRels repository is governed by its maintainers and community contributors. Core repositories define shared release tooling, schemas, APIs, or platform components that other SemRels repositories depend on.

## Scope

This governance applies to all code, workflows, and documentation in the repository.

## Decision Making

We use lazy consensus for routine changes. Breaking changes, architectural changes, and cross-repository policy updates require discussion in an Issue or Discussion before merge.

## Maintainer Expectations

- At least one maintainer approval is required for routine pull requests.
- Two maintainer approvals are required for governance changes or other cross-cutting policy changes.
- Major changes should be documented before implementation.
