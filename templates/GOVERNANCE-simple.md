# Governance

## Overview

This repository is maintained with a lightweight governance model suitable for small SemRels repositories. Maintainers remain accountable for project direction while welcoming community contributions.

## Scope

This governance applies to the full repository unless a subdirectory documents a more specific override.

## Decision Making

Maintainers use lazy consensus for routine changes. If no objection is raised within 7 days, a proposed change may proceed.

## Maintainer Expectations

- One maintainer approval is sufficient for routine pull requests.
- Governance changes should be reviewed by all active maintainers.
- Repository ownership changes must update `MAINTAINERS.md`.
